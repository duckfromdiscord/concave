# concave
Add artists, add API credentials, track concerts/shows. MusicBrainz powered.

## Supported APIs
- [MusicBrainz](https://musicbrainz.org/). - No API key needed, but you will add MBIDs to your artists when creating them
- [TicketMaster](https://developer.ticketmaster.com/products-and-docs/) API. Thanks so much for making this free 💖
- PR your own!
